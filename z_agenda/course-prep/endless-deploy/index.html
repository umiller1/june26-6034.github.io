My GitHub Pages deployment never seems to finish!


For some students, GitHub Pages seems to have trouble publishing their websites after they successfully commit and push their changes.

This means that your files may have uploaded to GitHub just fine, but your live website never seems to finish updating. You may even try to commit and push again, only for that one to immediately cancel because GitHub still believes the previous one that failed is still queued up and in progress.

GitHub's publishing service can sometimes become delayed and then get stuck while trying to publish websites. Unfortunately, there's not much you can do to fix this yourself!

Regardless of the reason, there is a simple way to handle the situation without wasting time or losing your work. You'll still be able to submit, it just may look a bit different until your next successful deployment.

Submit your website anyway

  1. First, make sure you've successfully committed and pushed your changes using GitHub Desktop. Ensure you're not facing the Endless Push error instead on GitHub Desktop.

    If your changes appear in your GitHub repository, your files have been uploaded successfully!

    Next, search for and copy your GitHub Pages website link for the assignment. You'll still want to submit even if your website isn't working just yet.

    Your website may display a 404 error, show an older version, or display a blank page. This is fine as that will change upon your next successfuly deployment.

    Still submit what you have and make sure it is the correct URL by cross-referencing your remove repository's folder and file structure!

Try to publish your website again later

  1. Once you've submitted your assignment, give GitHub some time to finish processing its publishing requests. Thirty minutes to an hour should suffice.

    You can also revisit your website link to see if it has finished publishing. Sometimes, it may say queued but has been finished for a while.

    After waiting a while, return to GitHub Desktop and try committing and pushing again if your website still hasn't updated.

    If it was successful this time, then great! You can either resubmit or update your instructor accordingly.

    If it was not successful this time, then give it some more time before you try to check for an update or commit and push again.
